# Afbeeldingen voor de André Galvão pagina

Zet hier de volgende bestanden neer (exacte bestandsnamen aanhouden):

- `hero.jpg` — grote hero-foto van André Galvão (staand/breed formaat, wordt full-bleed als achtergrond met donkere overlay getoond)
- `about.jpg` — foto van André Galvão (bv. competitie) voor de "Who is André Galvão" sectie

Sponsor- en mediapartner-logo's kunnen in `public/images/andregalvao/sponsors/` en `public/images/andregalvao/media/` geplaatst worden.
Voeg ze vervolgens toe aan de `sponsors` / `mediaPartners` arrays bovenin `src/pages/AndreGalvaoPage.tsx`.

Zolang een bestand hier nog ontbreekt, toont de pagina automatisch een nette placeholder in plaats van een gebroken afbeelding.
